# 네이버 블로그 자동 발행 도구

마크다운 파일 하나를 네이버 블로그에 발행합니다. **내 PC에서 실행합니다.**

```bash
npm run publish -- posts/글.md
```

---

## 왜 내 PC에서 실행하나요

네이버는 블로그 글쓰기용 공식 API를 제공하지 않습니다. 검색 API·데이터랩 API는 있지만
글 발행은 불가능합니다. 그래서 이 도구는 브라우저(Chromium)를 직접 띄워 사람이 하듯
에디터를 조작합니다. 로그인 세션이 필요하므로 서버가 아니라 내 PC에서 돌아가야 합니다.

아이디·비밀번호는 이 저장소 어디에도 저장하지 않습니다. `npm run login` 으로 브라우저에서
한 번 직접 로그인하면 세션만 `.auth/` 에 저장되고, 이후 발행은 그 세션을 재사용합니다.

---

## 설치

Node.js 20 이상이 필요합니다.

```bash
npm install
npx playwright install chromium
```

`.env` 파일을 만들고 블로그 아이디를 채웁니다.

```bash
cp .env.example .env
```

블로그 주소가 `https://blog.naver.com/hong1234` 이면 `BLOG_ID=hong1234` 입니다.

---

## 최초 1회: 로그인

```bash
npm run login
```

브라우저가 열립니다. 네이버에 직접 로그인하세요(2단계 인증이 있다면 그것까지).
로그인이 확인되면 세션을 저장하고 브라우저가 닫힙니다.

세션이 만료되면 발행할 때 안내가 나옵니다. 그때 이 명령을 다시 실행하면 됩니다.

> **`.auth/naver.json` 은 비밀번호와 같습니다.** 이 파일이 있으면 비밀번호 없이도 계정에
> 접근할 수 있습니다. 공유하거나 커밋하지 마세요. `.gitignore` 에 이미 등록되어 있지만,
> **이 저장소는 public** 이므로 한 번 더 확인하는 편이 좋습니다.

---

## 글 쓰기

`posts/` 아래에 마크다운 파일을 만듭니다. 맨 위 프론트매터에 제목·태그·카테고리를 씁니다.

```markdown
---
title: 글 제목
tags: [태그1, 태그2]
category: 분양정보
---

본문을 여기에 씁니다.

## 소제목

- 항목 하나
- 항목 둘
```

- `title` 은 필수입니다.
- `tags` 는 최대 30개(네이버 제한). 생략 가능합니다.
- `category` 는 블로그에 실제로 있는 카테고리 이름이어야 합니다. 생략하면 기본 카테고리로 갑니다.

---

## 발행

처음에는 **연습 모드부터** 올라가는 것을 권합니다.

```bash
# 1단계 — 발행 직전까지만. 스크린샷으로 확인
npm run publish -- posts/example.md --dry-run

# 2단계 — 임시저장. 네이버에서 실제로 확인
npm run publish -- posts/example.md --draft

# 3단계 — 실제 발행
npm run publish -- posts/example.md
```

### 옵션

| 옵션 | 설명 |
|---|---|
| `--dry-run` | 발행하지 않고 `screenshots/` 에 스크린샷만 남깁니다 |
| `--draft` | 발행 대신 임시저장합니다 |
| `--headless` | 브라우저 창을 띄우지 않습니다 |
| `--yes` | 발행 전 확인 질문을 건너뜁니다 |

`--headless` 없이 실행하면 브라우저가 보입니다. 처음에는 켜두는 편이 좋습니다.
뭐가 잘못됐는지 눈으로 바로 알 수 있습니다.

---

## 알아두실 점

### 서식은 평문으로 들어갑니다

굵게·기울임 같은 마크다운 서식은 기호를 떼고 평문으로 입력됩니다. 소제목과 글머리 기호는
줄바꿈과 `•` 로 유지됩니다.

서식을 실제로 입히려면 에디터 툴바를 일일이 조작해야 하는데, 그 방식은 네이버 UI가 조금만
바뀌어도 글이 깨진 채 발행됩니다. 강조가 필요하면 발행 후 에디터에서 직접 입히는 편이
빠르고 안전합니다.

### 발행 간격

기본 60초입니다. 연속 발행은 자동화 탐지에 걸릴 수 있어 간격을 둡니다.
`.env` 의 `MIN_PUBLISH_INTERVAL_SEC` 으로 조정할 수 있습니다.

### 네이버 이용약관

네이버 이용약관은 자동화 도구 사용을 제한할 수 있습니다. 또한 짧은 시간에 많은 글을
올리면 저품질 문서로 판정되거나 이용이 제한될 수 있습니다. 본인 계정에 본인 글을
올리는 용도로, 사람이 쓰는 속도를 넘지 않게 쓰시기 바랍니다.

## 안 될 때

### "[발행] 버튼을 찾지 못했습니다" 같은 오류

네이버가 에디터 UI를 바꾸면 CSS 셀렉터가 깨집니다. 클래스명에 해시가 붙어 있어
(`publish_btn__m9KHH` 처럼) 개편 때마다 바뀝니다.

셀렉터는 전부 **`src/selectors.ts` 한 파일**에 모여 있습니다. 이 파일만 고치면 됩니다.

새 셀렉터 찾는 법:

1. 크롬에서 블로그 글쓰기 화면을 엽니다
2. `F12` → 왼쪽 위 요소 선택 아이콘(↖) 클릭 → 해당 버튼을 클릭
3. 하이라이트된 요소에서 우클릭 → **Copy → Copy selector**
4. `src/selectors.ts` 의 해당 항목 맨 앞에 붙여넣습니다 (쉼표로 구분된 후보 목록입니다)
5. `npm run publish -- posts/example.md --dry-run` 으로 다시 확인

### "로그인 세션이 만료되었습니다"

`npm run login` 을 다시 실행하세요.

### 글이 이상하게 들어갔을 때

이전에 쓰다 만 글이 있으면 네이버가 복구 팝업을 띄웁니다. 이 도구는 그 팝업을 취소하고
새 글로 시작하지만, 팝업 모양이 바뀌면 놓칠 수 있습니다. `--dry-run` 스크린샷에서
확인하세요.

## 구조

```
src/
  cli.ts         명령행 진입점, 인자 파싱
  login.ts       최초 로그인 → 세션 저장
  publish.ts     발행 흐름
  editor.ts      iframe 진입, contenteditable 입력
  selectors.ts   CSS 셀렉터 (UI 바뀌면 여기만 수정)
  loader.ts      마크다운 → Post
  browser.ts     브라우저 실행, 세션 로드
  config.ts      환경변수
  types.ts       Post 타입
posts/           발행할 글
.auth/           로그인 세션 (커밋 금지)
screenshots/     --dry-run 결과
```
